# Jarvis

![Screenshot of Jarvis Dashboard](jarvis.png)

This project is my spin on a Jarvis-esque dashboard which I could leave running and observe:

1. Time
2. Date
3. System Info (Memory, CPU, Disk, Temps)

## Future Plans

1. Weather API information for my local area
2. Some ASCII art in the corner lol

## End Goal

I imagine myself loading this on a microprocessor, swapping out the system info for more "day-to-day useful information," and displaying this on a small screen somewhere in my bedroom.

I could leave time and date, but go more in depth on weather information. Maybe even show the traffic patterns of the day in my local area. Maybe even a GIF!

Just spitballing here.
